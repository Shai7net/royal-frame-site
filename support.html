פתרונות מהירים

Quick answers

המחשב או הטלפון מבקשים לבצע צימוד מחדשThe PC or phone asks to pair again

ודאו שאתם מחוברים לאותו בית ושמסך הקיר הראשי מופיע כמחובר. אם קוד קודם פג, צרו קוד חדש מהמסך הראשי והשלימו את הצימוד לפני שיתוף מדיה.

Confirm that both devices are using the same Home and that the primary wall display is online. If the old code expired, generate a new code on the primary display and complete pairing before sharing media.

תמונה או סרטון לא הגיעו למסךA photo or video did not reach the screen

בדקו שהחשבון שאישר Google Drive עדיין מחובר, שהקובץ עדיין קיים ב־Drive ושהמסך מחובר לרשת. אין לשלוח קישורי Drive או קודי צימוד בדוא״ל התמיכה.

Check that the Google Drive account is still authorized, the file remains in Drive and the screen is online. Do not email Drive links or pairing codes to support.

הודעה נשארת במצב “נשלחה”A message remains in “sent” state

אישור “הוצגה” נכתב רק לאחר שמסך מחובר מציג את ההודעה. ודאו שהמסך פעיל ושאותו בית נבחר בשני המכשירים.

“Displayed” is recorded only after an online screen renders the message. Confirm that the screen is active and that both devices have selected the same Home.

איזה מידע לצרף לבקשת תמיכה?What should I include in a support request?

דגם המכשיר, Android או Windows, מספר גרסה, השעה המשוערת שבה התקלה קרתה וצילום מסך ללא מידע פרטי. לעולם אל תשלחו סיסמה, קוד צימוד פעיל או קישור פרטי לקובץ.

Include device model, Android or Windows, version number, approximate time of the problem and a screenshot with private information removed. Never send a password, active pairing code or private file link.
